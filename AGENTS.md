# Working in this repository

Read `CLAUDE.md` before changing homepage behavior or the public build. It defines the scroll, background-control, and publication contracts.

For a new blog post, an edit to an existing post, or a publishing request, read `docs/blog-publishing.md` first. It contains the paste-to-agent workflow, content schema, preview commands, validation, and publication steps. Preserve supplied prose unless the user requests editing. Show the local preview before pushing unless the user explicitly authorizes publication without a preview.
